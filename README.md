# 🚀 Career Forge AI

Career Forge AI is a full-stack AI-powered interview preparation platform that helps job seekers generate personalized interview reports based on their resume and target job description.

Users can upload their resume, receive AI-generated interview insights, identify strengths and weaknesses, and prepare with tailored technical and behavioral interview questions.

---

## ✨ Features

### 🔐 Authentication
- User Registration & Login
- JWT Authentication
- Refresh Token Authentication
- Protected Routes
- Secure Cookie-based Authentication

### 🤖 AI Interview Analysis
- Resume Upload
- Target Job Description Support
- AI-powered Resume Analysis
- Personalized Interview Report Generation
- Strengths & Weaknesses Analysis
- Improvement Suggestions

### 💼 Interview Preparation
- Technical Interview Questions
- Behavioral Interview Questions
- AI-generated Answers
- 14-Day Personalized Preparation Plan
- Interview Readiness Score

### 📊 Dashboard
- View All Reports
- Report Details
- Delete Reports
- Responsive Dashboard UI

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/career-forge-ai.git
```

```
cd career-forge-ai
```

---

## Backend

```
cd backend
npm install
```

Create `.env`

```env
PORT=

MONGODB_URI=

JWT_ACCESS_SECRET=

JWT_REFRESH_SECRET=

GROQ_API_KEY=

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=

FRONTEND_URL=
```

Run

```bash
npm run dev
```

---

## Frontend

```
cd frontend
npm install
```

Create `.env`

```env
VITE_API_URL=
```

Run

```bash
npm run dev
```
